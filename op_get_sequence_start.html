GET /sequence/start

Start Advanced Sequence.

Query parameters

  • skipValidation boolean

    Skip validation of the sequence

Responses

  • 200 application/json

    Successful response

    • Error string

    • Success boolean

  • 409 application/json

    Sequence not initialized / Sequence already running

    • Success boolean

  • 500 application/json

    Internal server error, Unknown error
